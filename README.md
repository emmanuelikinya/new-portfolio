
# Emmanuel Ikinya Portfolio

This is a modern, responsive multi-page React portfolio site built with Vite.

## Features
- Home, About, Projects, Resume, and Contact pages
- Modern, clean, and accessible design
- Fast development with Vite and React
- Easy to customize and extend

## Getting Started

1. Install dependencies:
   ```sh
   npm install
   ```
2. Start the development server:
   ```sh
   npm run dev
   ```
3. Open your browser at [http://localhost:5173](http://localhost:5173)

## Project Structure
- `src/` - Main source code
- `src/pages/` - Page components (Home, About, Projects, Resume, Contact)
- `src/components/` - Reusable UI components

## Customization
Replace placeholder content in each section with your own information, projects, and contact details.
